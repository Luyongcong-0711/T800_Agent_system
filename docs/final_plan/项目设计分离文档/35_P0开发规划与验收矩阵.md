## 主 Agent 总规则

主 Agent 必须遵守：

1. 每个开发任务先创建 dev task。
2. 每个 SubAgent 必须有 `read_scope` 和 `write_scope`。
3. 多个 SubAgent 的 `write_scope` 默认不能重叠。
4. 只读 SubAgent 可以并发。
5. 写入型 SubAgent 只有在写入范围互不重叠时可以并发。
6. 任何 SubAgent 不能直接宣布任务完成。
7. SubAgent 产物必须回到主 Agent 汇总审核。
8. 主 Agent 最终运行测试、整理风险、写 verification report。
9. 每个阶段完成后必须更新开发日志。
10. 未测试项必须明确写出原因。
