## Job 测试

| 测试 | 期望 |
| --- | --- |
| 重复创建同一 `document_ingestion_job` | 返回已有非终态 Job，不重复入库 |
| 不同文档同时入库 | 可以并发执行 |
| 同一文档版本重复入库 | 被幂等或互斥策略拦截 |
| 同一知识库 embedding 重建并发 | 只允许一个 active Job |
| Worker 崩溃后重启 | Job 进入 `recovering` 并重放事件恢复 leaf_state |
| Milvus / Neo4j 写入结果未知 | 进入 `unknown_outcome`，先按 operation_id 探测再重试 |
| `jobs_index.json` 损坏 | 从 `jobs/*/manifest.json` 和 `leaf_state.json` 重建 |
| 取消 running Job | 到安全检查点后 cancelled，无法判断结果时进入 unknown_outcome |
| MCP capability refresh 失败 | 旧 snapshot 保留，标记 stale，不清空可用工具 |

## P0 总体验收矩阵

| 模块 | P0 验收用例 | 通过标准 |
| --- | --- | --- |
| 本地环境 | docker compose 启动 MinIO / Milvus / Neo4j / Redis | 四个服务健康，Agent Server 可连接 |
| 远程配置 | 把 MinIO / Milvus / Neo4j / Redis 任一项切到远程 | 配置保存 secret_ref，连接测试返回脱敏健康状态 |
| Provider | OpenAI-compatible 非流式和流式调用 | 返回统一 `ModelResult` / `ModelStreamEvent` |
| Provider | Anthropic 非流式和流式调用 | 返回统一 `ModelResult` / `ModelStreamEvent` |
| Provider | context overflow | Hermes 压缩后最多重试一次，失败可见 |
| Thread | 新建多个对话窗口 | 旧会话不删除，历史消息可恢复 |
| Run SSE | 主对话流中断 | 使用 `last_event_id` 补发，不重复渲染 |
| Job | 同一文档重复入库 | 返回已有非终态 Job 或互斥阻断 |
| Job | Worker 崩溃 | 进入 `recovering`，重放 event 恢复 leaf_state |
| 文档入库 | PDF / DOCX / Markdown / HTML / Excel / CSV / TXT / 代码 / 图片 OCR | 都有 Parser Router 入口、manifest 状态和失败提示 |
| 文档入库 | embedding batch 部分失败 | manifest 标记 `embedded_partial`，成功 chunk 可检索，失败 chunk 可重试 |
| RAG | Milvus 检索命中 chunk | 能按 chunk_id 回源 MinIO 正文和 citation |
| GraphRAG | 两实体关系查询 | Neo4j 只读多跳查询可用，最大深度 2 |
| MCP | capability refresh | 创建 Job，失败保留旧 snapshot 并标记 stale |
| Memory | 模型判断用户偏好应保存 | 调用 `memory_upsert` 写入，前端可见 |
| Memory | 用户删除记忆 | 后续 memory snapshot 不再注入，deny-list 阻止重复写回 |
| Skill | 系统初始无业务 Skill | `skill_index.json` 可为空，管理工具可用 |
| Skill | 用户批准创建 Skill | 写入 manifest，更新 skill_index，可被 `skill_search` 找到 |
| Skill Script | 脚本写文件 | 只能写 overlay，生成 staged diff，审批后提交 |
| SubAgent | 并发只读分析 | 多个 SubAgent 可并发，结果回主 Agent 汇总 |
| SubAgent | 写入范围冲突 | 自动串行或拒绝，不直接改最终结论 |
| 日志 | 生成诊断包 | 脱敏通过，不包含 API key、token、密码、密文和 nonce/tag |
